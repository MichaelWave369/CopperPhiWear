# ΦJunction — V1.0 integration increment
Open http://127.0.0.1:8000/workbench/junction.html from the local launcher. Create a default pattern network, import a hybrid project or load a hybrid vault snapshot. Every path starts with separate start/end nodes, even when coordinates coincide. Select endpoints A and B, then explicitly add a bond only when coordinates coincide within 0.000001 normalized units. No implicit jumpers, intersection detection, or interior path splitting. Removing a bond recomputes components. Set distinct analysis terminals; disconnected networks are reported separately from ideal zero resistance. A documented uniform linear resistance (ohm/m) is optional; absent it, no resistance estimate is displayed. The existing ideal DC solver is limited to 150 connected nodes. Contact resistance, real textile construction and material tolerances are not modeled. Component colors repeat; numbered endpoint selectors disambiguate overlapping coordinates. Limits: 300 paths, 100000 points, 600 bonds. Export/import standalone versioned junction JSON and export derived reports. Junction records are not stored in ΦVault yet. No medical, RF, PPE or powered garment model; detached tests only. Browser interaction and physical measurements remain unverified.
