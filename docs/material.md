# ΦMaterial — material documentation and review

Open the local launcher and choose ΦMaterial. Start with the blank record: all quantities unknown and checks pending. Enter the actual supplier, product and lot, composition, substrate and substrate lot, care instructions and document reference. For each copper mass fraction, linear mass (g/m) and linear resistance (ohm/m), record a supplier value or measured value with a source reference; leave unknown quantities null. Do not invent values. A measured value should identify the method, instrument, units and actual specimen in its source reference. The schema validates ranges and presence, not accuracy or provenance.

Seven checklist items record pending, documented or issue with an observation/document reference required for non-pending states. Enter actual printed calibration measurements (50 mm horizontal, 20 mm vertical targets) and reference to the print record, or leave null. The report uses the existing exploratory ±1% calibration check. Issues take priority over incomplete documentation. Even fully documented records produce only "documentation-ready-for-independent-review"; no automatic permission for an experiment or wearable. The tool cannot establish skin compatibility or safety. Independent assessment of materials, procedure and equipment is required. Use only detached samples, nonconductive practice first, no powered or grounded garments, no on-body testing.

Export the validated material JSON and report; keep local with the pilot manifest and raw register. This module is standalone, with explicit file import/export, no automatic vault or laboratory synchronization. Browser tests use synthetic fixtures only. No physical material has been qualified.
