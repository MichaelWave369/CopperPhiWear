# ΦLaboratory V0.6
Run the existing local server and visit http://127.0.0.1:8000/workbench/laboratory.html. Register independent detached swatches, then append measurements with unique IDs. Eleven groups: nine geometry families, plain fabric control and straight-conductor reference. Use at least three independently fabricated swatches per condition for exploratory work; not a power calculation. Match material lot, substrate, size, conductor mass or length, measurement method, and conditions. Record mismatches. Randomize measurement order where feasible. Define probe configuration, bend radius and abrasion method before measurement (record in method/notes). Use suitable low-energy instruments only on detached samples. Record meter uncertainty if available, not invented uncertainty. Record open, failed and missing separately, with reasons and null numeric values. Record numeric zero only if actually observed. Record damage even when no numeric measurement exists.

The register is in memory, not durable storage. Export complete JSON before closing; import replaces the register only after validation and confirmation when records exist. CSV contains measurements; the JSON is the authoritative record including sample metadata and uncertainty. No data transmission. Do not enter personal or health information.

Summary uses each sample median for baseline and each stage/cycle count, so repeated readings do not inflate independent sample counts. Percent changes are paired to a positive baseline median; zero or missing baselines are excluded from percent change, not substituted. Groups are descriptive by geometry, not matched automatically by material or method. Failure counts are readings, damaged count is samples. No statistical significance, combined uncertainty, causal or health estimates. Do not interpret unmatched groups as controlled comparisons. Preserve raw records and report all failures and missingness. Browser UI and physical tests remain unverified.
