# ΦHybrid V0.8
Start the existing local server; visit http://127.0.0.1:8000/workbench/hybrid.html. Select a preset or edit the JSON tree, then compile. Save the concept SVG or versioned project JSON. Presets: nested pockets, golden branching recursion, 3/6/9 strand braid composition, and four-way pocket mosaic. These are geometric analogies inspired by recursive research, not physical holography or a mathematical implementation of set theory.

## Composition language
A motif node has type "motif", pattern (one of nine V0.2 families), optional parameters (strands, turns, depth, ratio, cells), and optional transform. A group has type "group", nonempty children, and optional transform. Transform fields x,y specify the center in the parent tile, scale is 0.01–1, rotation is degrees −360 to 360. Defaults are x=50, y=50, scale=1, rotation=0. A point is transformed around its local tile center; child transforms apply before parent transforms. Physical tile size is specified once at project level. Out-of-bounds centerlines are rejected, not clipped. No connectivity or crossing order is inferred.

Depth ≤6 including root, ≤256 node visits, ≤12 children per group, ≤6000 paths and ≤500000 sampled points. Preset mosaic is capped at three levels. Geometry lengths count overlaps and occupancy is approximate. Project import validates and canonicalizes the tree. SVG is a concept swatch; Hybrid fabrication now accepts saved compositions; optimization and garment panels do not yet accept them. No external runtime dependencies, no health, shielding, durability or garment fit claims. Browser UI and physical samples not yet validated.
