# ΦFabrication V0.5
Start the existing local server, then open http://127.0.0.1:8000/workbench/fabrication.html. Export single-page A4 or US Letter SVG reference sheets, or import a version-1 ΦGarment project to group identical swatch designs by pattern and size. Export inventory CSV and full JSON. No internet or accounts. The SVG specifies physical page dimensions in millimeters, but print applications and drivers may rescale. Use actual size, no fit-to-page, then measure the horizontal 50 mm and vertical 20 mm calibration bars. Both must be within the selected ±1% exploratory tolerance; a failed check requires adjustment and reprint. This is not a calibrated instrument. Oversized tiles are flagged, never silently scaled. One reference per distinct motif and tile size; quantity is recorded separately. All motifs use default geometry parameters except tile size. No tiled multi-page printing yet. The inventory estimates yarn only if material inputs are documented; substrate, liner, attachment hardware, sewing and finishing allowances remain manual. No garment cutting pattern, weaving sequence, electrical connections, or clinical conclusions. Start with nonconductive practice swatches and detached conductive samples; follow docs/protocol.md. Automated tests cover model logic, not physical prints or browser UI.

## V1.0 development: recursive hybrid references
Import a version-1 ΦHybrid project in the recursive section, or use its dedicated vault snapshot loader. The compiler replays the saved tree and original tile size, and the same calibrated sheet renderer draws the transformed centerlines with 0.001 mm coordinate rounding. The chosen paper is shared with the original fabrication interface. Quantity changes the planned total centerline length, not the geometry or number of pages in the reference. Oversized tiles are reported without rescaling; resize deliberately in ΦHybrid and save a new project. Export the reference SVG and the JSON manifest containing the canonical composition and derived metrics. ΦBridge reports print feasibility from captured hybrid records. No automatic garment integration, seam allowances, actual material mass, multipage printing or electrical bonds. Physical print calibration and swatch fabrication remain unverified.
