# ΦGarment Studio V0.4
Start the existing local HTTP server and visit http://127.0.0.1:8000/workbench/garment.html. No external dependencies, accounts or data transmission. Nine candidate zones start disabled and unmeasured. Enter measurements of distinct flat liner areas (not body circumference); the schematic is not to scale. Hood, neck and cuffs are excluded. Enable a subset only, or ensure adjacent areas such as back halves and center do not overlap. Sleeves are flat rectangular estimates, not wraparound patterns. Select motifs, tile size, gap and margin, then calculate. Supply documented yarn properties optionally; no partial material inventory is inferred. Export/import versioned project JSON, or export the derived inventory separately. All geometry uses V0.2 defaults aside from tile size. Lengths use rounded tile centerlines and exclude connecting yarn, stitch allowances and substrate. No seam-aware nesting or fit verification, no actual tailoring or validated wearable, no electrical connections, no combined garment resistance. Begin physical work with detached swatches and follow docs/protocol.md. No health claims.
